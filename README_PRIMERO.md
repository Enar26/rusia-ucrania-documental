# Empieza aquí — paquete Codex V5 Cloud

**Repositorio ya creado y entorno Codex Cloud conectado:** `Enar26/rusia-ucrania-documental`.

## Cómo llevar este paquete a Codex Cloud
1. Descarga el ZIP de ChatGPT y **extrae su contenido** en tu computadora.
2. Abre el repositorio GitHub en el navegador, estando en la rama `main`.
3. Selecciona **Add file → Upload files**. Arrastra **los archivos y la carpeta `referencias` extraídos** (NO solo el `.zip`). Deben quedar directamente en la raíz del repositorio: `AGENTS.md`, `PROYECTO_MAESTRO_V5.md`, `PLAN_HISTORICO_V4.md`, etc., además de `referencias/`.
4. Comprueba la estructura y confirma el upload con el botón de commit de GitHub (solo contiene especificaciones y prototipos; aún no es un despliegue).
5. Abre Codex Cloud, selecciona el entorno ya preparado y asegúrate de que usa este repositorio y que está actualizado con ese commit.
6. Copia el contenido de **`PROMPT_01_AUDITORIA_CLOUD.md`** como **primer mensaje** de Codex. La primera tarea es análisis, no programación.
7. Revisa la propuesta con ChatGPT; al aprobarla usa `PROMPT_02_IMPLEMENTACION.md` para pedir las escenas 4–7.

Si Codex indica que los archivos no están presentes, asegúrate de que el entorno usa el repositorio y el commit correctos. Los archivos descargados en tu PC no aparecen automáticamente en Codex Cloud.

## Qué paquete NO subir
No hace falta subir los ZIP anteriores V3/V4 junto con V5: se han incorporado los materiales relevantes y las especificaciones vigentes.

## Protección de datos
El repositorio es público: no incluir datos privados de estudiantes, correos, claves, fotos personales ni nombres completos sin su aprobación. Los mapas y las fotografías históricos requieren revisión de atribución y permisos.

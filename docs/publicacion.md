# GitHub Pages

La rama de publicación `gh-pages` usa un directorio generado con `python3 tools/preparar-pages.py DIRECTORIO_VACÍO`. Contiene la interfaz, los recursos locales, el catálogo y el ZIP actualizado. Los guiones, planes, pruebas y evidencias permanecen en las ramas de trabajo.

Si GitHub solicita configurar el origen, entra como propietario en **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona **gh-pages** y **/(root)**, y guarda. Activa **Enforce HTTPS** cuando se habilite. Tras finalizar el despliegue, abre la dirección que aparece en esa pantalla. [Instrucciones de GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

El catálogo y los avisos de `assets/` acompañan el material. Las fotos y vídeos de TEXTY/Nakypilo llevan la atribución correspondiente. Se conservan las condiciones de OpenStax para el uso educativo sin fines comerciales, las licencias tipográficas y las de los mapas. Las capas territoriales del atlas son una elaboración por provincia. Cada escena enlaza sus referencias sin distribuir los archivos de control territorial originales.
